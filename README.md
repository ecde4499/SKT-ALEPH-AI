# 나를 소개하는 한 페이지

README v1.0의 내용을 바탕으로 제작한 개인 소개 페이지입니다.

## 구성
- 소개: 나를 한 문장으로 설명
- 관심사: 게임 / 조립과 퍼즐 / 컴퓨터와 디지털 도구
- 강점: 계획 / 몰입 / 듣고 정리하며 반응하기
- 일하는 방식: 구체적인 요청, 우선순위, 빠른 변경사항 공유
- 목표: SKT 인턴십을 향한 현재 방향
- 근거: 실제 학습 행동 기록

## 접근성
- Skip link 제공
- 주요 상호작용은 `<button>`으로 구현
- Tab / Enter / Space 키로 사용 가능
- `prefers-reduced-motion` 대응
- 명확한 제목 구조와 높은 텍스트 대비
- 가로 넘침을 피하도록 반응형 레이아웃 적용

## 실행
`index.html`을 브라우저에서 열면 됩니다.
