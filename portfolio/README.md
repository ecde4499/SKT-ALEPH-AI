# BR-A Portfolio (public static copy)

공개 주소는 별도 Render 정적 사이트로 배포합니다. 과제1 소개 페이지나 과제8 서비스는 변경하지 않습니다.

- index.html: 이름과 한 줄 소개, 3문단 자기소개, 세 가지 실제 사례, 대표작(Protective DNS·Clean4U), 그 외 연구·학습 앱 링크
- data/summary.json: 2026.08.11~11.10 최신 121건 직접 재집계: 기록 날짜 61일·아침 61건·학습 회고 60건·실천 40일·일부 11일·미실천 9일(자기평가; 공식 출석률 아님)
- resume.html / statement.html / experience.html: 공개 서류 열람용 HTML 판
- research.html: 과제10 논문 공개용 요약. 전체 원문이 아님
- main.js: summary.json의 펼쳐 보기 수치 및 승인된 문단만 표시

문서 DOCX 3종과 Python 결정적 갱신 소스·실행 증거는 별도 BR-A 제출 ZIP으로 제공됩니다.

공개 연락 수단은 GitHub Issues 링크이며, 실제 입사 지원 전에 본인이 최종 확인해야 합니다.
타인 실명 및 리추얼 원문은 올리지 않았습니다.

- 공개용 이력서는 제공된 지원서와 최근 재검토 경력기술서를 바탕으로 갱신합니다. 회사별 재직 종료월은 문서 간 차이가 있어 증빙과 최종 대조해야 합니다. 원본 리추얼과 개인 연락처·상세주소는 게시하지 않습니다.
