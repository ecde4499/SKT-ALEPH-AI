4인 팀 캡스톤 · 보안01

Protective DNS

가짜 피해구제·기관 사칭 사이트의 접속 위험을 줄이기 위한 URL 판정 서비스

담당: Python 기반 URL 위험도 판단 기준과 BLOCK·WARN·ALLOW·UNKNOWN 정책 엔진, 위험도 제안 로직.

진행: 위협 근거를 검토하고 점수 제안과 DNS 차단 집행을 구분했습니다. DNS 담당 팀원과 판정 결과의 전달 범위를 검토했습니다.

팀의 합성 DNS 응답 테스트 240/240은 기능 일치 기록이며, 실제 피싱 탐지율은 아닙니다.
